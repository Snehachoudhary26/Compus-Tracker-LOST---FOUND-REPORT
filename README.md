# 🎯 CampusTracker — Lost & Found Platform

A smart lost and found platform for campus communities.

## 🌐 Live URLs
- **Frontend:** https://campus-tracker-nu.vercel.app
- **Backend API:** https://campus-tracker-api.onrender.com

## 🛠 Tech Stack
- **Frontend:** HTML, CSS, JavaScript — deployed on Vercel
- **Backend:** Node.js + Express — deployed on Render
- **Database:** MongoDB Atlas
- **Auth:** JWT Tokens

## 🚀 Features
- Report lost and found items
- Smart item matching
- Real-time messaging
- Admin panel
- Notifications
- Mobile responsive PWA

## ⚙️ Environment Variables (Render)
MONGO_URI = your mongodb atlas url
JWT_SECRET = your secret key

## 📝 Note
Backend is hosted on Render free tier.
First request may take 50 seconds to wake up.
